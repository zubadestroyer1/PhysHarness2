# Research network and scientific discourse

User-approved scope: implement the six discussed improvements, with GPT-6 Sol coding and root planning, review and tests. Goal is autonomous collaborative mathematics with useful, attributed communication, not agent count or messages as a proxy for proof. Existing dirty work and private evidence must be preserved.

## Behavior
1. Operator can seed a bounded diverse portfolio of independently instructed roots in one atomic idempotent command. Mathematical methods are supplied/selected by researchers and models, never forced by role taxonomy.
2. Agents receive recruitment guidance and can discover opt-in research directory entries, available capacity, current public assignments and existing teams. A single atomic recruit creates branch plus task and a durable relationship under original experiment budget; old APIs cannot bypass campaign task admission.
3. Teams are voluntary labels/subscriptions, not access-control grants. Agents can join/leave and contact other groups under existing ideas policy. Operator can request synthesis of selected discussions using an ordinary attributed task; synthesis has no acceptance authority.
4. A persistent research board has topics, append-only posts, replies, question/finding/objection/help/update/synthesis kinds, immutable artifact references, explicit unverified attribution, subscriptions and keyset paging. Threads bind exact experiment/target/environment. Exact source posts and objections remain available when a digest summarizes them.
5. Agents receive bounded relevant updates at safe runtime boundaries without polling models or interrupting an uncertain paid call. Durable event sequence/delivery identity and explicit acknowledgement prevent silent omission on crash; delivery is at-least-once with visible IDs, never an exactly-once claim. Bounded raw excerpts are called excerpts, never model-written synthesis.
6. Capacity admission and scheduling stay central: one experiment ledger, no automatic budget increases. Pending/total task caps, deterministic fair dispatch across branches, existing leases/fences, no short-term-progress cancellation. Resource requests are inspectable demand signals; actual execution is authorized by shared scheduler. Configurable independent exploration and voluntary cross-pollination preserve diversity.

## Contracts and boundaries
Canonical PostgreSQL/SQLite records and events remain authority. No new orchestration engine. Use existing idempotency/fencing/service patterns. HTTP, Python client and MCP call same services as model tools. All new mutations require idempotency; CAS applies to revisions where state is overwritten. Defaults preserve existing direct-mode experiments. Cross-branch discourse requires ideas sharing. Directory exposes only explicitly published summaries, no native checkpoints, private task results or unpublished objectives. Subscription/membership never overrides sharing. Models cannot mark ideas verified.

New features should live in focused discussion/workforce/runtime modules, not a general social platform. One experiment-wide event stream filtered server-side is acceptable; avoid per-message all-to-all copies. Use bounded DB queries and stable cursors; cursor/ack must bind reader and experiment, prevent skipping unseen deliveries. Delivery payloads have hard byte/count bounds, truncation markers and retrieval IDs. Stale target/environment or fenced identity fails loudly.

## Evidence required
Real service integration with concurrent simulated workers, provider mock transcripts proving updates reach subsequent model requests, idempotency/fault tests, authorization/privacy tests, fair dispatch and budget tests, strict tool schema validation, full regression suite. PostgreSQL/Temporal checks when affected and available. Record live vs replay separately. No paid model run or fleet/SOTA effectiveness claim follows from passing synthetic tests. Prior two-trial budget is completed, not a new authorization to spend. VM remains stopped unless required for integration tests, then stop it afterward.
