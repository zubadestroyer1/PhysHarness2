# Long-horizon release review

This is a working checklist, not qualification evidence. Each assertion needs an observed test or explicitly recorded limit.

| Area | Required evidence |
| --- | --- |
| Scientific context | Exact target/review/current task, explicit partial indices, accepted-reference validation, original artifact hashes, private state excluded. |
| Handoff notes | Useful approach and open obligations discoverable across sessions; old notes labeled unverified/stale where appropriate; current canonical evidence wins. |
| Native compaction | Multiple actual/fake provider compactions, encrypted content preserved, crossing tool calls paired, exact discarded history archived, fresh scientific anchor, no usage reset. |
| Resource authority | Every descendant/successor stays within one ledger; actual overruns recorded; provably unsent failures distinct from uncertain provider calls. |
| Recovery | First-session and successor settled checkpoints; handoff-before-issue and consumed-before-start crashes; pending tools/model calls not replayed blindly. |
| Concurrency | One-slot parent wait yields capacity; active unrelated siblings do not block handoff; stale fences rejected; duplicate ticket consumption cannot spawn duplicate authority. |
| Workspace | Exact files restored into new execution identity; policy/source hashes checked; ticket persisted before destruction; unknown provider effects retained. |
| Temporal | Real local engine runs continuation/waiting and restart routing; no opaque provider retry after heartbeat timeout. |
| Finishing | Explicit source-and-submit tool; queued checks drain after generation stop; operation completion separate from accepted proof status. |
| Public tools | API/client/MCP coverage for bounded context/history/artifact access and mailbox; selective sharing remains enforced. |
| VM acceptance | Current pinned image/runtime, fresh scoped qualification packet, kernel and independent-kernel controls and attacks, observed RAM/container health. |
| Live trial | Two fresh $25 known-result attempts, first cannot retrieve old accepted proof; recorded low compaction threshold; exact usage and feature-use counts; no operator-assisted success mislabeled autonomous. |
| Shutdown | Live monitor paused; dedicated VM stopped; no active child allocations, checker containers or unreported uncertain work. |

Unavailable cloud deployments, fleet endurance, model-performance generalization, and unexercised native runtime adapters must remain explicitly unqualified.
