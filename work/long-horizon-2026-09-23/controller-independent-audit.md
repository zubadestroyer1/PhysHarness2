# Independent controller audit (2026-09-23)

Read-only review of `research_worker.py` and `continuation.py` after native and VM integration. Findings sent to the controller owner and root; this is an audit snapshot, not a claim they remain unfixed.

1. **VM handoff crash window:** the native session reaches terminal `handed_off` before `prepare_handoff` exports the VM and `record_workspace_handoff` saves its ticket. Expired-lease recovery can issue a continuation with no workspace ticket. If any source-fence workspace record exists, including a later-destroyed one, ticket absence must block reconciliation rather than silently lose files. Add a crash-at-this-boundary test.
2. **Unbound model reservation crash window:** `generation_started` reserves budget, then records a task-scoped model-reservation binding in another transaction. Death between those writes leaves reserved budget without a task binding; task-scoped settled checks cannot find it. Make reserve-and-bind atomic or reconcile the deterministic operation ID; test this exact window.
3. **Compaction anchor drift:** refreshed `context_anchor` currently contains working context and handoff notes but omits the initial task objective, allowed model configurations, and instructions for unresolved gaps and independent proof. Native compaction discards the initial prompt. Re-anchor those authoritative fields after confirming target/review freshness; inspect a post-compaction request in a fake-provider test.

Native runtime now supports narrowly safe adoption of a persisted `running` checkpoint only at `settled_boundary=True` with no pending model or tool effect, and no active task in that runtime. Controller must additionally prove expired prior ownership, settle/reconcile old worker capacity, and verify exact source checkpoint and unchanged configuration. Its recovery tests should cover first-session and successor crashes, consumed ticket before new session creation, pending tool nonreplay, sibling reservations, stale targets/models/leases, and workspace archive restoration.
