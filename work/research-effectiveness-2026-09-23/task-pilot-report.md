# Pilot operator implementation report

The new `pilot_ops.py` prepares one fresh reviewed projection attempt and one fresh reviewed purity attempt in a private isolated SQLite database. It imports only the six campaign/problem/review records through the historical helper. Preparation creates two paused tasks, reserves $25 per target, refuses a second attempt ID or conflicting campaign experiment, and makes no model, Docker, or verifier call. The initial start/create/pause sequence is required by the service task allocation contract. **The 7200-second experiment wall clock starts during preparation**, so prepare the real private database immediately before serial launch; do not prepare it days ahead or alter `started_at` on resume.

`run` is the sole paid entry point. It requires the configured operator identity, private model credential, recorded `gpt-6-sol` input/output prices, exact verifier registry, a supplied genuine workbench qualification report, and live `run_preflight`. The factory binds the pinned final image, dedicated Colima socket, target environment digest, 256 MiB workspace archive quota, zero local external invoice, and supplied report SHA-256. The run command creates a 0700 worktree mounted TMPDIR and sets Python `tempfile.tempdir` only for the run process, then restores the previous values. The runner uses one worker, a 7200-second timeout, and the canonical $25 budget. A second active launch, uncertain reservation, ambiguous existing session, or extra campaign allocation is refused. Existing terminal tasks return status without a paid call.

`status` emits allowlisted metadata: task and experiment execution status, exact target accepted receipt status through the canonical acceptance predicate, separate claim count, ledger and uncertain reservations, real runtime generation/tool/compaction/stagnation event counts, workspace command counts, and durable handoff reasons. Continuation mode is reported only for the latest consumed ticket per task; older modes are explicitly counted as unknown because the current durable event stream does not retain their mode. Status never emits artifact text or native checkpoint content. `export` writes private artifact bytes and the immutable reproduction manifest, checks each SHA-256, then runs `validate_export`. Its result establishes integrity, not scientific qualification.
